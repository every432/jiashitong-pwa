# Android与PWA功能对照表

| 功能 | Android | PWA | 验收边界 |
|---|---|---|---|
| 本人/恢复成员昵称 | boundAuthUid映射、空/失败区分 | 同规则，官方profile补充本人 | 真实账号待验收 |
| 其他成员昵称 | 读取现有listMembers | 同接口 | 云端兼容候选未部署 |
| 邀请与认证 | 保留原流程、身份与协议 | 精确阶段、同UID、持久未知结果保护 | Safari外部SERVICE_ERROR尚需定位 |
| 六模块角标 | 明确待处理/未读混合规则 | 同规则 | 不把消息总数解释为事项总数 |
| 个人开支 | 统一录入、连续记账、查询与历史保留 | 同功能，异步存储确认 | 无数据结构迁移 |
| 登录布局 | 登录上方、创建加入下方 | 同结构 | 合法认证先于家庭写入 |
| 编译/单测 | Debug编译、Lint、58项JUnit | TypeScript、Lint、166项单测 | 不是真机/线上权限证据 |
| 缓存更新 | 沿用应用升级方式 | 原SW安全更新+新版本缓存名 | 不清除业务存储 |
