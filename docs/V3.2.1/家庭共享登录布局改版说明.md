# 家庭共享登录布局改版说明
双端默认进入已有账号密码登录，“欢迎回来”位于上方，用户名/邮箱、密码和紫色“登录家庭共享”按钮直接可见；保留验证码登录、密码显示隐藏与忘记密码。
下方“第一次使用？”包含创建家庭和加入家庭。创建进入正式注册认证，认证完成后使用现有家庭列表创建；不会未认证直接建家庭。加入入口保留10位一次性加入/恢复，已登录正式账号保留12位旧码兼容。底部保留注册新账号。
合法会话继续恢复进入已有家庭流程；原UID核对、成员关系、角色及账号管理未取消。邀请码未知结果有明确核对入口，不自动新建或替换UID。
窄屏、大字体与键盘短视口在Chromium模拟中通过；真实iPhone触摸、Safari持久会话与Android实际布局待人工验收。
