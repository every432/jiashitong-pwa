# 家庭开支统计改版说明
双端流程为：月/年与类别查询 → 总金额/笔数 → 紫色“＋记一笔开支” → 原彩色分类卡片 → 最近5笔/全部记录。原有管理编辑、缩放、CSV保留。
录入必填金额、类别、日期（今天），备注选填。保存并再记一笔保留日期与类别便于连续录入，清空金额/备注；保存并返回关闭录入。编辑已有记录保留其ID，避免新增副本。
金额沿用整数分和原范围，不修改分类及字段，不做破坏性迁移，不上传个人开支。PWA等待现有资料存储队列确认后才关闭，失败留草稿并重用记录ID；Androidcommit失败不关闭，继续使用同一attemptId。空金额及快速点击不能新增重复记录。
年度/月度/分类筛选沿用原数据；月份/年份输入无效时不会把所有历史记录当正确期间总额。原用户缩放继续保存在原键中。
